PwnTrace

PwnTrace is a Python-based security assessment tool that helps automate some common steps in penetration testing. It currently performs:

Nmap service and version scanning
CVE lookup using the NVD API
CVSS-based vulnerability prioritization
Exploit information lookup
MITRE ATT&CK technique mapping
Potential attack-path generation
Attack-path visualization
PDF, JSON and CSV report generation
Important

PwnTrace does not automatically exploit targets. The attack paths generated by the tool are potential paths based on the available vulnerability information. They should be manually verified before treating them as real attack paths.

The MITRE ATT&CK mappings are also heuristic. They are generated using information such as NVD descriptions, CVSS, CWE and the services found during scanning. They are not official MITRE mappings.

Setup

Create a virtual environment and install the dependencies:

pip install -r requirements.txt

If you're developing the project, you can also install:

pip install -r requirements-dev.txt

Copy .env.example to .env and add an NVD API key if you have one.

Nmap needs to be installed separately and added to PATH.

Run the application with:

python run.py

By default, it runs at 127.0.0.1:5000.

Evaluation

The tool should be tested in controlled and intentionally vulnerable lab environments. Some useful things to measure are:

How accurately services and versions are identified
How relevant the CVE matches are
False-positive CVE matches
Accuracy of ATT&CK mappings
How closely generated attack paths match manually created paths
Time taken compared with doing the analysis manually

These metrics should only be reported after actually testing and measuring them.
